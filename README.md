# Data-analysis

El presente proyecto busca integrar los conocimientos adquiridos durante la cursada, aplicando las etapas fundamentales del análisis de datos sobre un conjunto de datos real.
El objetivo es que cada estudiante sea capaz de explorar, limpiar, transformar, visualizar e interpretar datos, comunicando sus resultados de manera clara, ordenada y fundamentada.

Consignas:
-	Seleccionar un dataset real (de Kaggle, datasets públicos u otras fuentes abiertas) con no menos de 3.000 registros y al menos 5 columnas relevantes.
-	Desarrollar un notebook en Google Colab donde se realicen las etapas del proceso analítico:
o	Carga y exploración inicial del dataset.
o	Limpieza y tratamiento de datos faltantes, duplicados o inconsistentes.
o	Transformaciones necesarias (creación de nuevas columnas, uniones, normalización, filtrados, etc.).
o	Visualizaciones que permitan interpretar patrones, relaciones o tendencias.
o	Conclusiones que respondan a la pregunta de análisis y resuman los hallazgos.
-	Presentar el proyecto de manera oral frente a la clase, mostrando el notebook o una breve presentación (PPT o PDF).
